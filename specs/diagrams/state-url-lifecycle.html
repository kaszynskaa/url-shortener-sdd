● Active GET /{code} → 302 Found Redirects to longUrl. Click event recorded asynchronously.
◌ Expired GET /{code} → 410 Gone TTL elapsed. No redirect. Owner may extend TTL to restore.
⊘ Suspended GET /{code} → 451 Unavailable Admin-flagged abuse. RFC 7725 — intentional suppression, not unknown code.
✕ Deleted GET /{code} → 404 Not Found Soft-deleted. Row retained for audit; hard purge after 90-day retention window.

State Transition Table

Complete enumeration of every valid transition, its trigger, and actor.

From To Trigger Actor HTTP after transition
— → Active POST /api/v1/urls succeeds API client 302 Found
Active → Expired expires_at timestamp passes (sweeper or on-access) System 410 Gone
Active → Deleted DELETE /api/v1/urls/{code} Owner 404 Not Found
Active → Suspended Abuse policy / admin flag Admin / System 451 Unavailable
Expired → Active PATCH /api/v1/urls/{code} extends TTL Owner 302 Found (resumes)
Expired → Deleted Owner deletes or auto-purge (30-day grace) Owner / System 404 Not Found
Suspended → Active Admin clears suspension flag Admin 302 Found (resumes)
Suspended → Deleted Admin removes or owner requests deletion Admin / Owner 404 Not Found
Deleted → — Terminal state — no recovery — 404 Not Found (permanent)
Short-code reuse freeze: A short_code from a Deleted URL MUST NOT be reused for 30 days to avoid confusion for users who bookmarked the old link.

451 vs 404 for Suspended: HTTP 451 (Unavailable For Legal Reasons) is used instead of 404 to signal intentional suppression rather than an unknown code, per RFC 7725.
